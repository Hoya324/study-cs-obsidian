# 시작 진단 질문

이 목록은 시험지가 아니라 **다음 질문을 고르는 후보**다. 한 번에 하나만 묻고, 답변에 드러난 연결을 따라 순서를 바꾼다.

## 현재 활성 질문

> [!question]
> 브라우저에서 Spring API를 한 번 호출했을 때, 요청은 어디를 거쳐 어떤 서버 자원을 사용하고 응답으로 돌아온다고 생각하나요?

연결: [[서버란 무엇인가]] · [[HTTP 요청과 응답]] · [[Spring 요청 생명주기]] · [[요청이 소비하는 리소스]]

## 후속 후보 — 아직 답하지 않는다

1. [[부하와 병목|요청량이 늘면 서버는 왜 느려지는가?]]
2. [[요청이 소비하는 리소스|요청이 계산할 때와 기다릴 때 각각 무엇을 점유하는가?]]
3. [[Tomcat 스레드 풀]]과 [[JDBC 커넥션 풀]]의 역할·대기열·포화 증상은 무엇이 다른가?
4. [[DB 서버와 애플리케이션 서버|DB 서버와 애플리케이션 서버가 주로 보호해야 하는 자원은 어떻게 다른가?]]
5. [[큐잉과 백프레셔|과부하 때 요청을 더 기다리게 하는 것과 거부하는 것은 어떤 차이가 있는가?]]
6. [[타임아웃과 재시도|timeout과 retry가 장애를 증폭하는 조건은 무엇인가?]]
7. [[멱등성과 중복 처리|재시도해도 중복 지급되지 않는다고 어디까지 보장할 수 있는가?]]
8. 네 프로젝트 중 하나에서 위 개념을 어떤 수치·실패 시나리오로 검증했는가?

## 답변 평가 기준

- level 0: 설명하지 못함
- level 1: 용어를 한 문장으로 정의
- level 2: 요청 흐름과 내부 동작 연결
- level 3: 실패 조건·증상·지표 연결
- level 4: 대안·트레이드오프·프로젝트 증거 연결

자신감만으로 level을 올리지 않는다. 답변 원문, 실험 또는 검증된 설명을 근거로 남긴다.
