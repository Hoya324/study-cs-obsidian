# 면접 질문 색인

면접 답변은 암기 문장이 아니라 `정의 → 동작 → 실패 → 지표 → 선택과 비용 → 프로젝트 증거`로 조립한다.

## 서버와 요청

- [[서버란 무엇인가]]를 프로그램·머신·역할로 구분해 설명하라.
- [[Tomcat 스레드 풀]] 포화와 [[JDBC 커넥션 풀]] 포화의 증상·지표를 비교하라.
- [[요청이 소비하는 리소스]]를 CPU 작업과 대기 작업으로 나눠 설명하라.

## 데이터와 정합성

- [[트랜잭션 락과 격리 수준]]이 막는 문제와 막지 못하는 문제를 설명하라.
- [[멱등성과 중복 처리]]가 retry와 메시지 재전달에 필요한 이유를 설명하라.
- [[분산 락과 CAS]]를 언제 쓰고 어떤 반례를 확인할지 설명하라.

## 성능과 운영

- [[부하와 병목]]을 요청률·요청당 비용·제한 자원으로 설명하라.
- [[큐잉과 백프레셔]]에서 queue를 늘리는 것의 장단점을 설명하라.
- [[관측 가능성]]으로 느린 요청의 원인을 좁히는 순서를 설명하라.
