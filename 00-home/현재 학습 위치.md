# 현재 학습 위치

이 노트는 [[학습 시스템 설정]]의 체크포인트 규칙을 따른다.

## 현재 경로

[[백엔드 전체 지도]] → [[05 JDBC JPA RDBMS와 MySQL]] → [[Real MySQL 8.0 1]] → [[MySQL 외워둘 핵심 설정]] → [[MySQL 상황별 설정 점검표]]

## 지금 할 일

1. [[MySQL 외워둘 핵심 설정]]의 A급 표와 30초 회상 카드만 먼저 읽는다.
2. 숫자는 외우지 않고 `설정 → 자원·장애 → 지표` 연결만 기억한다.
3. 실제 문제가 생기면 [[MySQL 상황별 설정 점검표]]에서 증상으로 찾아간다.

기존 내구성 질문은 [[운영용 my.cnf 예시는 그대로 복사해도 되는가]]에 보존한다. 지금 당장 답할 필요는 없다.

## 아직 열지 않을 다음 질문

- 설정 출처 조회 질문은 [[SET PERSIST는 my.cnf를 수정하는가]]에 보존되어 있다.
- GLOBAL과 기존 SESSION 질문은 [[MySQL GLOBAL 변수 변경은 기존 세션에 적용되는가]]에 보존되어 있다.
- buffer cache 후속 질문은 [[InnoDB 버퍼 풀과 MyISAM 키 캐시는 무엇인가]]에 보존되어 있다.
- upgrade rollback 질문은 [[MySQL 8.0에서 9.0으로 어떻게 업그레이드하는가]]에 보존되어 있다.
- Unix socket의 port 무시 질문은 [[MySQL localhost 연결은 어떤 전송 방식을 사용하는가]]에 보존되어 있다.
- [[DBMS의 안정성은 어떻게 판단하는가]]는 더 읽은 뒤 보완한다.

## 세션 체크포인트

- 마지막 완료: 사진의 설정을 A급 핵심·상황별 조회·문서에서 찾을 항목으로 다시 분리
- 현재 level: 2 — runtime·persistence·설정 우선순위를 설명했으며, durability 설정의 장애 trade-off는 아직 직접 설명하지 않음
- 다음 세션 시작점: 새 내용을 읽을 때 핵심 암기 항목과 상황별 점검 항목에 추가
