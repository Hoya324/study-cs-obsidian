## 지금 할 일

- 다음 입력은 `05 트랜잭션과 잠금`부터 이어 간다.
- `04-아키텍쳐/`는 장 폴더로 유지한다.
- `4.4.x` 입력은 [[4.4 MySQL 로그 파일]]에 번호 순서대로 누적한다.
- 사용자가 다음 하위 절을 보내면 원문을 보존하고 해당 큰 절 note에 정리·보완한다.
- 확인 질문은 canonical note 안에서 답이 접힌 callout으로 복습한다.

04 아키텍처의 사용자 제공 범위를 완료했다. 4.4에서는 error·general·slow log를 “서버 장애·수신 SQL·완료된 느린 SQL”로 구분하고, 아직 실행 중인 query는 PROCESSLIST·Performance Schema·sys로 보는 운영 흐름을 정리했다. 현재 `realmysql 8.0.44`는 error log를 `stderr`로 내보내므로 Docker에서는 `docker logs`가 1차 경로다. 4.2.13·4.3은 별도 사용자 입력이 없어 상세 노트를 만들지 않았다.

## 아직 열지 않을 다음 질문

- 설정 출처 조회 질문은 [[SET PERSIST는 my.cnf를 수정하는가]]에 보존되어 있다.
- GLOBAL과 기존 SESSION 질문은 [[MySQL GLOBAL 변수 변경은 기존 세션에 적용되는가]]에 보존되어 있다.
- buffer cache 후속 질문은 [[InnoDB 버퍼 풀과 MyISAM 키 캐시는 무엇인가]]에 보존되어 있다.
- upgrade rollback 질문은 [[MySQL 8.0에서 9.0으로 어떻게 업그레이드하는가]]에 보존되어 있다.
- Unix socket의 port 무시 질문은 [[MySQL localhost 연결은 어떤 전송 방식을 사용하는가]]에 보존되어 있다.
- [[DBMS의 안정성은 어떻게 판단하는가]]는 더 읽은 뒤 보완한다.
