# 학습 시스템 설정

이 Vault는 `$backend-cs-learning` 스킬과 함께 `질문 → 내 답변 → 진단 → 개념 연결 → 자료·실험 → 재설명 → 다음 질문`을 반복한다. 폴더나 책을 처음부터 끝까지 소비하는 계획이 아니라, 현재 답변에서 드러난 연결의 빈틈을 따라간다.

## 세션 시작

1. [[현재 학습 위치]]에서 현재 경로와 활성 질문을 읽는다.
2. [[학습 기록]]에서 최신 세션을 확인한다.
3. 활성 질문 하나만 자신의 말로 답한다. 모르면 모른다고 말한다.

## 진단과 level

- level 0: 아직 설명 증거가 없다.
- level 1: 한 문장 정의를 자기 말로 설명한다.
- level 2: 내부 동작과 요청 흐름 속 위치를 설명한다.
- level 3: 실패 조건, 증상, 측정 지표를 연결한다.
- level 4: 대안과 트레이드오프를 프로젝트 수치·재현 조건으로 방어한다.

confidence는 느낌이며 level의 증거가 아니다. level을 올릴 때는 관련 개념 노트의 `level 근거`와 세션 노트의 `level 변경과 근거`에 답변 인용, 실험 또는 검증된 설명을 남긴다.

## 한 번의 답변이 바꾸는 범위

원칙적으로 질문 노트, 직접 관련된 개념 노트, [[현재 학습 위치]], 당일 세션 노트만 바꾼다. Markdown이 원본이고 Canvas는 지도 구조가 실제로 달라질 때만 함께 바꾼다.

## 자료 선택

1. [[도서 색인]]과 [[강의 색인]]의 보유 자료
2. [[공식 레퍼런스 색인]]의 공식 문서
3. 위 자료로 메우기 어려운 빈틈이 확인됐을 때만 새 책·강의 추천

## 세션 종료 체크포인트

- 사용자의 답변 원문
- 맞는 연결과 아직 끊긴 연결
- level 변경 여부와 근거
- 생성하거나 수정한 노트
- 다음 세션 첫 질문 하나

세션이 중간에 끊기면 완성된 척하지 않는다. 마지막으로 보존된 답변과 [[현재 학습 위치]]에서 그대로 재개한다.

## 보호 규칙

- 이력서 원본, 연락처, 주소, 계정, 토큰과 비밀값을 Vault에 복사하지 않는다.
- 프로젝트 노트에 정제된 사실보다 강한 보장을 만들지 않는다.
- 기존 Notion과 외부 저장소는 별도 승인 없이 수정하지 않는다.
- 검증이 실패하면 이번 변경만 고치고 이전 학습 기록은 보존한다.
