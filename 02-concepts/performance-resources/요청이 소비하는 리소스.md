# 요청이 소비하는 리소스

## 한 문장 정의

요청은 실행 중 CPU·메모리·스레드·커넥션·소켓·디스크·네트워크와 외부 시스템의 시간 예산을 소비한다.

## 요청 흐름 속 위치

수신부터 응답까지 모든 단계에 놓인다.

## 왜 필요한가

이 개념을 알아야 요청의 계산 시간과 대기 시간을 구분하고, 실패가 어느 경계에서 시작됐는지 설명할 수 있다.

## 내부 동작

현재는 큰 틀을 잡는 시드다. 다음 진단에서 자신의 말로 흐름을 설명한 뒤 내부 구조와 반례를 채운다.

## 소비하는 리소스

CPU time, allocated bytes, worker time, DB connection time, I/O와 dependency budget를 사용하거나 점유한다.

## 실패 조건과 관찰되는 증상

어느 한 제한 자원의 서비스 시간이나 대기열이 늘면 end-to-end 지연과 timeout이 커진다.

## 측정 지표와 확인 방법

단계별 duration, utilization, saturation, queue, error를 요청 지연 및 오류와 같은 시간축에서 확인한다.

## 해결 전략과 트레이드오프

요청당 비용과 동시 점유 시간을 분리해 측정하고 가장 먼저 포화되는 자원의 수요·상한·대기를 줄인다.
