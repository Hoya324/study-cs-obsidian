# 객체 메모리와 컬렉션

## 한 문장 정의

Java 객체와 컬렉션은 heap을 사용하며 자료구조 선택은 탐색·삽입 비용과 할당량·지역성에 영향을 준다.

## 요청 흐름 속 위치

DTO 변환, 캐시, 집계와 Batch 처리에서 객체를 생성·보관하는 구간에 놓인다.

## 왜 필요한가

이 개념을 알아야 요청의 계산 시간과 대기 시간을 구분하고, 실패가 어느 경계에서 시작됐는지 설명할 수 있다.

## 내부 동작

현재는 큰 틀을 잡는 시드다. 다음 진단에서 자신의 말로 흐름을 설명한 뒤 내부 구조와 반례를 채운다.

## 소비하는 리소스

heap, CPU, object header, backing array·node를 사용하거나 점유한다.

## 실패 조건과 관찰되는 증상

불필요한 중간 컬렉션과 무제한 보관은 GC 압력과 OOM을 만든다.

## 측정 지표와 확인 방법

allocation profile, retained size, collection size, GC pressure를 요청 지연 및 오류와 같은 시간축에서 확인한다.

## 해결 전략과 트레이드오프

자료 크기와 접근 패턴에 맞는 구조를 고르고 streaming·batching으로 상한을 둔다.
