# 멱등성과 중복 처리

## 한 문장 정의

멱등성은 같은 의도의 요청이 반복되어도 관찰 가능한 결과가 한 번 처리한 것과 같도록 만드는 성질이다.

## 요청 흐름 속 위치

client retry, queue redelivery, Batch 재시작과 외부 API timeout 경계에 놓인다.

## 왜 필요한가

이 개념을 알아야 요청의 계산 시간과 대기 시간을 구분하고, 실패가 어느 경계에서 시작됐는지 설명할 수 있다.

## 내부 동작

현재는 큰 틀을 잡는 시드다. 다음 진단에서 자신의 말로 흐름을 설명한 뒤 내부 구조와 반례를 채운다.

## 소비하는 리소스

idempotency key, result/state store, unique constraint, retention를 사용하거나 점유한다.

## 실패 조건과 관찰되는 증상

키 범위·수명·원자성 오류는 중복 지급·중복 파일·다른 요청 오인으로 이어진다.

## 측정 지표와 확인 방법

duplicate attempt, dedup hit, state transition, retry success, conflict를 요청 지연 및 오류와 같은 시간축에서 확인한다.

## 해결 전략과 트레이드오프

업무 의도에서 안정된 키를 만들고 상태 저장과 side effect의 원자성·보존 기간을 명시한다.
