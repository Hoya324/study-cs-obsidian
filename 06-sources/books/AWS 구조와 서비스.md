# AWS 구조와 서비스

- 형태: 도서
- 상태: 보유
- 역할: AWS 전체 구조와 주요 서비스의 역할을 그림으로 배치하는 입문서
- 공식 페이지: https://wikibook.co.kr/awsguide/

## 이 자료를 여는 조건

VPC·load balancer·compute·database·storage의 배치와 책임을 잡을 때

## 장·절 또는 섹션 찾기 규칙

현재 질문의 핵심 용어를 목차에서 찾고, `읽을 위치 → 답할 질문 → 완료 증거`를 세트로 기록한다. 처음부터 순서대로 완독하지 않는다.

## 완료 증거

- 자신의 말로 요청 흐름에 연결한 설명
- 실패 조건과 지표 한 쌍
- 프로젝트 또는 작은 실험에 적용한 결과

## 저작권 원칙
