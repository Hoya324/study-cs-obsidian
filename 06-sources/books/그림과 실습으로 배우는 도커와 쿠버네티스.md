# 그림과 실습으로 배우는 도커와 쿠버네티스

- 형태: 도서
- 상태: 보유
- 역할: 컨테이너·image·network·volume·Compose와 Kubernetes를 그림과 실습으로 잡는 입문서
- 공식 페이지: https://wikibook.co.kr/dkkb/

## 이 자료를 여는 조건

JVM 프로세스가 container와 pod에서 어떻게 격리·배치되는지 확인할 때

## 장·절 또는 섹션 찾기 규칙

현재 질문의 핵심 용어를 목차에서 찾고, `읽을 위치 → 답할 질문 → 완료 증거`를 세트로 기록한다. 처음부터 순서대로 완독하지 않는다.

## 완료 증거

- 자신의 말로 요청 흐름에 연결한 설명
- 실패 조건과 지표 한 쌍
- 프로젝트 또는 작은 실험에 적용한 결과

## 저작권 원칙
