# 02-2.2.3 서버 연결 테스트

## 읽은 위치

- 책: [[Real MySQL 8.0 1]]
- 범위: 02 설치와 설정 · 2.2.3 서버 연결 테스트

## 내 메모 원문

> 로컬 연결에서 --host 세팅에 따라 Unix domain socket을 이용하는 여부가 나뉨 (따로 너가 정리)

## 핵심 정리

Unix 계열의 MySQL 클라이언트는 연결 대상이 로컬이라는 사실만으로 방식을 정하지 않는다. `--host`와 `--protocol`을 해석해 Unix domain socket 또는 TCP/IP를 선택한다.

| 명령의 핵심 설정 | 기본 전송 방식 | 포트 사용 |
|---|---|---|
| host 생략 | Unix domain socket | 사용하지 않음 |
| `--host=localhost` | Unix domain socket | `--port`를 지정해도 무시될 수 있음 |
| `--host=127.0.0.1` | TCP/IP loopback | 사용함 |
| `--host=::1` | TCP/IP IPv6 loopback | 사용함 |
| `--host=localhost --protocol=TCP` | TCP/IP loopback | 사용함 |
| `--protocol=SOCKET --socket=<경로>` | 지정한 Unix domain socket | 사용하지 않음 |

`localhost`는 단순히 `127.0.0.1`로 변환되는 이름이 아니다. Unix 계열의 MySQL 클라이언트가 이를 특별하게 해석해 기본적으로 socket 파일을 선택한다. `--protocol`을 명시하면 이 규칙보다 우선한다.

## Unix domain socket이란

같은 운영체제 안의 프로세스가 파일 시스템의 경로를 접점으로 삼아 통신하는 IPC 방식이다. 경로가 보이지만 요청 데이터가 일반 파일처럼 디스크에 저장되는 것은 아니다.

- IP 주소와 TCP 포트를 거치지 않는다.
- 같은 호스트의 프로세스끼리만 사용할 수 있다.
- socket 파일 경로와 권한이 연결 가능 여부에 영향을 준다.
- TCP/IP보다 처리 경로가 짧지만, 실제 쿼리에서는 SQL 실행 비용이 더 큰 경우가 많다.

## 현재 Docker 환경에서 확인한 결과

`realmysql` 컨테이너 내부의 MySQL 8.0.44에서 `mysql ... -e status`로 확인했다.

```text
host 생략                         → Localhost via UNIX socket
--host=localhost                 → Localhost via UNIX socket
--host=127.0.0.1                 → 127.0.0.1 via TCP/IP
--host=localhost --protocol=TCP  → localhost via TCP/IP
```

컨테이너 밖 macOS에서 `127.0.0.1:3306`으로 접근하면 Docker가 공개한 포트를 통과하므로 TCP/IP다. 반대로 컨테이너 내부에서 host를 생략한 `mysql` 명령은 컨테이너 내부 socket을 사용한다. 컨테이너의 `localhost`는 macOS 호스트가 아니라 그 컨테이너 자신이다.

## 자주 생기는 착각

- `localhost`와 `127.0.0.1`은 MySQL CLI에서 항상 같은 의미가 아니다.
- `--host=localhost --port=3307`만으로 TCP 3307 연결을 보장하지 않는다.
- socket 경로가 없는 오류와 TCP 포트 연결 거부는 서로 다른 연결 경로의 실패다.
- 이 선택 규칙은 MySQL 클라이언트 프로그램 기준이다. JDBC 드라이버 등 다른 클라이언트의 연결 규칙에 그대로 일반화하지 않는다.

## 확인 방법

MySQL 클라이언트 안에서 `status` 또는 `\s`를 실행하고 `Connection` 항목을 본다. 서버의 socket 경로는 `SHOW VARIABLES LIKE 'socket';`으로 확인한다.

## 지식 지도 연결

`클라이언트 옵션 → 전송 방식 선택 → socket 경로 또는 IP·port → mysqld 연결 → 인증 → SQL 실행`

## 현재 진단

- 포착한 연결: `--host`에 따라 Unix domain socket 사용 여부가 달라진다.
- 보완한 연결: `localhost`, loopback IP, `--protocol`, Docker 경계를 구체적으로 구분했다.
- level: 0 유지 — 방향은 맞지만 각 설정의 정확한 매핑을 아직 자신의 설명으로 확인하지 않았다.
