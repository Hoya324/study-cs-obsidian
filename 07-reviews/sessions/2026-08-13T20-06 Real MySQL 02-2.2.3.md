## 확인한 실험

MySQL 8.0.44 `realmysql` 컨테이너 내부에서 host 생략과 `localhost`는 Unix socket, `127.0.0.1`과 `localhost + --protocol=TCP`는 TCP/IP로 표시됐다.

## level 변경과 근거

level 변경 없음. host 설정이 socket 사용 여부를 바꾼다는 방향은 포착했지만, 정확한 매핑을 자신의 설명으로 확인하지 않았다.
