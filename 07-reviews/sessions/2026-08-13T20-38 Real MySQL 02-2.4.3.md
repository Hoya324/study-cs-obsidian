## 답과 연결

- InnoDB buffer pool은 table data page와 index page를 공유 cache하며 읽기·수정의 중심 작업 공간이다.
- MyISAM key cache는 index block만 cache하고 data block은 OS filesystem cache에 의존한다.
- 둘은 connection별 memory가 아니라 storage engine 전체가 공유하므로 Global이다.
- `Both`는 GLOBAL이 새 connection의 SESSION 초기값 역할을 하며 이후 두 값은 독립적이다.
- 최신 MySQL 8.0에는 `Scope: Session`이면서 startup 설정이 가능한 예외가 있어 `Scope`, `Cmd-Line`, `Option file`을 함께 확인해야 한다.

## level 변경과 근거

level 1 유지. “커넥션이 만들어지는 순간부터 해당 커넥션에서만 유효”하다고 SESSION의 수명은 설명했다. 그러나 현재 GLOBAL 값이 새 SESSION으로 복사되고 `SET GLOBAL`이 기존 SESSION에 소급되지 않는 과정은 아직 자신의 말로 확인하지 않았다.
