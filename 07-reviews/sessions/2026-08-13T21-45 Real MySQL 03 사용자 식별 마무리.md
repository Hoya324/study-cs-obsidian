>
> 오늘은 여기까지 모두 push하고 내일부터 04 아키텍처 공부 시작할거야

## 기록한 핵심

- MySQL 계정 identity는 `'user'@'host'`다.
- host는 IP뿐 아니라 hostname·network 범위·`localhost`·pattern을 포함할 수 있다.
- 후보가 여러 개면 더 구체적인 Host가 앞선 정렬에서 첫 일치 계정 하나가 선택된다.
- `USER()`는 client가 제시한 사용자·출발지, `CURRENT_USER()`는 실제 인증·권한 검사에 선택된 계정을 확인하는 데 쓴다.
- local socket과 TCP 연결 차이는 `'user'@'localhost'`와 IP 기반 계정 선택에 영향을 줄 수 있다.

## level 변경과 근거

사용자 식별 level 0 → 1. “사용자 계정 뿐 아니라 사용자의 접속지점(IP주소)도 계정의 일부”라는 설명으로 계정의 두 구성 요소를 자기 말로 정의했다. 실제 후보 선택 순서와 권한 문제를 진단한 증거는 아직 없어 level 2 이상으로 올리지 않는다.

## 미해결 연결

- 같은 사용자명에 Host가 다른 계정이 여러 개 있을 때 실제 선택 순서
- 인증된 account에 privilege와 role이 적용되는 과정
- Spring application의 실행 위치와 Docker network가 client host에 주는 영향
