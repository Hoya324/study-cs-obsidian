# 백엔드 전체 지도

> [!abstract] 이 지도가 답하는 질문
> Spring API 요청 하나는 어디를 지나고, 무엇을 소비하며, 어디에서 기다리고 실패하는가? 우리는 그것을 어떻게 측정하고 보호할 수 있는가?

## 요청의 전체 생명주기

`요구사항·클라이언트 → 네트워크·엣지 → Linux·JVM·Tomcat → Spring 애플리케이션 → DB·Redis·외부 시스템 → 응답·오류 → 운영 관측`

이 흐름에는 세 종류의 일이 반복된다.

- **계산한다**: CPU를 사용한다.
- **저장한다**: 메모리와 디스크를 사용한다.
- **기다린다**: 네트워크, 락, 큐, 스레드, 커넥션 같은 제한된 자원을 기다린다.
